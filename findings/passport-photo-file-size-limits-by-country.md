# Passport photo file size limits by country, in KB

95 passport, visa and ID documents publish a maximum file size for the digital photo, from 20 KB to 20,000 KB. Each limit by country, in KB, from the official rules.

Part of [Passport, visa and ID photo requirements](../README.md), by [WinPhoto ID](https://winphoto.io/id). Data: [CC BY 4.0](../LICENSE).

An online application can set how large the photo file may be, and sometimes how small. Of the 207 documents in WinPhoto ID's table, 95 publish a maximum file size: the smallest is 20 KB (Pakistani passport photo online), the largest 20,000 KB, and 7 are under 100 KB. 37 also set a minimum. The rules were read between 4 November 2026 and 20 November 2026. Only the issuing authority decides whether a photo is accepted.

The table runs from the smallest limit to the largest. 1,000 KB is 1 MB; a limit the rules give in MB is shown here in KB.

## Making a file fit

Lowering the JPEG quality a little takes a file under its limit with no change to the pixel size the rules ask for; resizing it smaller can break a pixel minimum. Each document's page makes or checks the file against both its pixel size and its file limit; [this page](https://winphoto.io/id/fix/file-too-large) explains the steps.

## Where the figures come from

Each row is one document in WinPhoto ID's table of 207 passport, visa and ID photo rules, read on the issuing authority's own page; the date in each row is the day that page was read. The whole table is [on one page](https://winphoto.io/id/photo-sizes), and the same data is open on GitHub under CC BY 4.0: [passport-photo-requirements](https://github.com/mnifzied-create/passport-photo-requirements). Only the issuing authority decides whether a photo is accepted. Each document's page links its official source, and most have a [free photo checker](https://winphoto.io/id) that measures your photo against those rules, in your browser.

## Questions

### What file size should a passport photo be?

It depends on the document. 95 documents in the table publish a maximum, from 20 KB to 20,000 KB, and 37 of them also a minimum; the table above gives each one.

### Which passport photo has the smallest file size limit?

Pakistani passport photo online (Pakistan): at most 20 KB.
